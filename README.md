# Plano 20K — Black & Purple

PWA pronto para GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para a raiz.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Abra o endereço no celular e instale como app.

## Regras importantes
- Nenhum gasto é descontado automaticamente.
- Quinta, dia 10 e dia 22 aparecem no calendário apenas como lembretes.
- Todo faturamento e todo gasto precisam ser lançados manualmente.
- Os dados ficam salvos no armazenamento local do navegador/aparelho.
